# Screenshots

Every image that lands in this folder gets a row here **in the same turn
it's saved**. The filename carries the timestamp, the sidecar note carries
the full story, and this table carries the thing you actually search by:
**what it shows and where it came from.**

Written by `AIOS/scripts/shot.py` — see that script for the whole design.
Don't hand-edit the table; run the script again on the same image (it
replaces the old row rather than duplicating it) or edit the sidecar note
next to the image instead.

> [!info] Sent in a chat that isn't backed up yet
> A screenshot sent during a live chat belongs to a transcript that doesn't
> exist yet — chat backups run on a delay (see `backup-cowork.py`). The
> sidecar note records the chat's name and id and marks `chat_saved: false`
> until the backup catches up. Run `python3 AIOS/scripts/shot.py --relink`
> afterwards and it turns into a real link by itself.
