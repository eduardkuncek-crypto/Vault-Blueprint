# Inbox

**Drop zone.** Dump things here with no naming and no frontmatter — the AI reads
the facts off them and files them properly.

| Folder | For |
|---|---|
| `Screenshots/` | Screenshots. Game state, errors, receipts, report cards, store pages |
| `Files/` | Everything else |

**A file sitting here is unprocessed.** Say *"check my inbox"* and it gets dealt
with.

Any photo or file you send in a chat should be copied here before it's used —
chat uploads get wiped between sessions, so an uncopied photo is a lost photo.

Once something's processed and filed, the original gets deleted or moved to
[[Attachments]] if it's embedded in a note — with your say-so.
