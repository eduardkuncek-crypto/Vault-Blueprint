# Attachments

Images that are **already embedded in a note**. This folder exists so screenshots
stop landing at the vault root.

Set it in Obsidian: **Settings → Files and links → Default location for new
attachments → In the folder specified below →** `Attachments`.

Nothing in here should be unreferenced. If an image isn't embedded anywhere, it
belongs in [[Inbox]] or the bin.
