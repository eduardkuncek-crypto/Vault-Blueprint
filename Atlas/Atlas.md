# Atlas

Things that stay true. If it isn't tied to a date and isn't a project you're
pushing, it lives here.

| Folder | What's in it |
|---|---|
| [[About Me]] | One note per subject about you as a person |
| [[Media]] | Shows, films, books and games you're actually watching, reading or playing |
| [[Worlds]] | Game worlds, saves, servers — coordinates, seeds, mods, versions |
| [[Knowledge]] | Notes written to understand a concept |
| [[Reference]] | Cheatsheets, specs, your own hardware and accounts |
| [[Clippings]] | Saved web articles with summaries |
| [[Radar]] | Things you're curious about but haven't started |

## Adding a new category

If a fact has no home and none of the above fits, make a new subfolder here with
an index note named after it, then register it in this table **and** in
[[vault-map]]. That's expected, not a last resort.

Don't create new top-level folders without thinking hard — the ACE split
(Atlas / Calendar / Efforts) is what everything else assumes.
